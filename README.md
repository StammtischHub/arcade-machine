# Arcade Machine

A custom-built arcade machine developed as part of a university engineering project.

The goal of the project was to design and build a fully functional arcade machine from scratch, combining mechanical design, carpentry , electronics, embedded systems and software development into a single system.

The resulting machine consists of a custom-designed wooden enclosure, a Raspberry Pi based gaming platform, integrated controls, LED lighting and supporting electronics.

---

## Project Overview

Unlike many software-only university assignments, this project required the combination of multiple engineering disciplines.

The project included:

- Mechanical design of the machine casing
- Creation of manufacturing drawings
- Carpentry of the wooden enclosure
- Electrical wiring and component integration
- Raspberry Pi setup and configuration
- Development of custom LED control software
- System assembly, testing and troubleshooting

The result is a fully operational arcade machine capable of running classic arcade games while providing a custom-built hardware experience.

The primary goal of the project was to gain practical experience in designing and building a complete system rather than focusing on a single technology.

## System Architecture

The arcade machine consists of multiple subsystems:

### Hardware

- Custom-built wooden casing
- Arcade buttons and joystick controls
- Display system
- Power distribution

### Computing Platform

- Raspberry Pi
- Linux-based operating system
- Retro gaming environment

### Lighting System

- Addressable LED strip
- Python-based control software
- Configurable lighting effects

### Documentation

- Engineering drawings
- Wiring diagrams
- Assembly documentation
